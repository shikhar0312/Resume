# Shikhar's Portfolio

Welcome to my personal resume and portfolio website!

## About This Project

This site is **vibe-coded** — built with a focus on aesthetics, smooth interactions, and a clean, minimalistic design.

It features:
- A responsive, single-page layout
- A fully customized dark/light mode toggle
- An interactive animated hero canvas that reacts to the cursor
- Clean typography and card-based project displays

## Deployment

The site is currently deployed on **Netlify**. You can view the live version here:
[https://shikharsinghresume.netlify.app](https://shikharsinghresume.netlify.app)

## Tech Stack
- HTML5
- CSS3 (Vanilla, custom properties for theming)
- JavaScript (Vanilla, canvas animation)
